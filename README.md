# Redesigned pages — drop into `Dev`

Unzip on top of your `duriah/duriah.github.io` checkout on the `Dev` branch. Files included here OVERWRITE existing ones; everything else (`pubs.qmd`, `teach.qmd`, `_variables_*.scss`, `styles.css`, `LICENSE`, `.nojekyll`, `research.ipynb`, etc.) is left untouched.

## Render

```bash
quarto preview          # live-reload server
quarto render           # one-shot build → docs/
```

## How a page is structured

Each redesigned `.qmd`:

- YAML frontmatter sets `theme: none` + `page-layout: custom` so Quarto skips its article wrapper and Bootstrap theme.
- Page-specific styles live in `include-in-header` as an inline `<style>` block in the YAML.
- The body is a single `{=html}` raw block containing the original HTML structure — `<main>`, `<section>`, `<div class="X">` etc.
- A tiny inline `<script>` at the top sets `document.body.dataset.page` and `document.body.dataset.screenLabel` so `site/site.js` can highlight the right nav link.
- `<span data-mount="bar"></span>` and `<span data-mount="foot"></span>` are placeholders that `site.js` swaps for the real nav and footer at runtime.
